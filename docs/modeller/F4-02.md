# Model kartı — F4-02: Bilgi tabanı araması

**Görev:** F4-02 · **Yazan:** Tahir · **Tarih:** 2026-10-26 · **Kod:** `asistan/arama.py`, test seti `asistan/degerlendirme/arama_sorulari.json`

> **Önceden kayıt:** test seti ve seçim kuralı, arama yöntemleri çalıştırılmadan commitlendi.

## Amaç
Asistan, tanım, açıklama ve "neden" sorularında bilgi tabanından (F4-01) doğru parçaları bulmalı. Sayısal sorular araçlarla cevaplanır (F4-03); bu arama yalnızca metin parçaları içindir.

F0-02'de küçük model (`multilingual-e5-small`) zıt anlamlı cümleleri karıştırmıştı: "iade çok" sorusuna "en az iade" belgesini getirdi.

## Tasarım
| yöntem | açıklama |
|---|---|
| `e5_kucuk` | `intfloat/multilingual-e5-small`, kosinüs benzerliği ("query:" / "passage:" önekleri) |
| `e5_buyuk` | `intfloat/multilingual-e5-base`, aynı |
| `bm25` | anahtar kelime: Türkçe küçük harf, kelime kökü olarak ilk 5 harf, k1 = 1,5, b = 0,75 |
| `hibrit_kucuk` | `e5_kucuk` + `bm25`, sıralı sonuçların birleştirilmesi (RRF, k = 60) |
| `hibrit_buyuk` | `e5_buyuk` + `bm25`, RRF |

- **Parça metni:** başlık + metin.
- **Test seti:** 30 soru. Konular: metrik tanımı, veri sözlüğü, model sonuçları, tavsiye, içgörü, kategori. Zıt anlam kontrolü için iki soru: "en çok iade edilen" ve "iadesi en az olan".

## Seçim kuralı
1. **Sahte** bilgi tabanında isabet@5 en yüksek olan yöntem seçilir.
2. Eşitlikte MRR@10 yüksek olan, o da eşitse daha hızlı olan seçilir.
3. Gerçek bilgi tabanındaki sonuç raporlanır, seçimde kullanılmaz.
